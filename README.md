# Infection Spread Simulator

## Overview
This project is a simple infection spread simulator built with Python.
It visualizes people in a 2D space and shows the initial infected individuals.

## Current Features
- Randomly generated positions for 100 people
- 5 initially infected individuals
- Visualization using matplotlib

## Tech Stack
- Python
- NumPy
- Matplotlib

## Future Work
- Add movement of agents
- Implement infection spread logic
- Add recovery system
- Build an interactive UI
  
## 概要
このプロジェクトは、Pythonで作成した簡単な感染症拡大シミュレーターです。
2次元空間内にいる人々を可視化し、初期感染者を表示します。
